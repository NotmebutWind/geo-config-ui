# GEO Config UI

面向产品经理的 GEO 测评配置生成器。无需安装软件或编写代码，在浏览器中填写目标产品、官网、竞品、测试问题与内部证据，即可生成标准的 `track-*.json` 配置文件。

## 使用方式

1. 打开 GitHub Pages 页面。
2. 按步骤填写产品资料。
3. 点击“生成 JSON 配置”，浏览器会下载文件。
4. 项目协作者可通过页面提供的入口，将文件上传到私有项目的 `config` 目录。

配置内容只保存在当前浏览器和下载文件中；公开页面不上传或存储业务资料。

## 本地预览

在本目录的 `public` 文件夹启动任意静态文件服务器即可。项目完整版也可以通过 `npm run config:ui` 运行，此时支持直接写入项目的 `config` 目录。
